# 🔥 20분 AMRAP 운동 카운터 (Pull-up / Push-up / Squat)

20분 동안 **[턱걸이 5개 ➔ 팔굽혀펴기 15개 ➔ 스쿼트 20개 = 1세트]** 루틴을 수행하며, 완료 시마다 원터치로 카운트하여 최대 달성 세트와 총 횟수를 측정하는 앱 및 웹사이트입니다.

---

## 🌐 1. 웹사이트 (Web App / PWA) 실행 방법

### 1) 원클릭 실행 (Python)
터미널에서 아래 명령어를 실행하면 웹서버가 켜지고 브라우저가 자동으로 열립니다:
```bash
python3 server.py
```
접속 주소: [http://localhost:8080](http://localhost:8080)

### 2) 웹 앱 주요 기능
- **PC & 모바일 반응형 디자인**: PC 모니터의 넓은 화면에서는 2열 대시보드로, 스마트폰/태블릿에서는 카드형 UI로 최적화 표시.
- **키보드 단축키 (PC 환경)**:
  - <kbd>Space</kbd> 또는 <kbd>Enter</kbd>: 현재 운동 완료 (+다음 단계로 전환)
  - <kbd>P</kbd>: 타이머 시작 / 일시정지
  - <kbd>U</kbd>: 이전 동작 되돌리기 (Undo)
  - <kbd>R</kbd>: 운동 초기화
  - <kbd>F</kbd>: 전체화면 (Fullscreen) 토글
- **🗣️ 한국어 음성 코치 (TTS)**: 단계 전환 시 "턱걸이 5개 완료", "팔굽혀펴기 15개 완료", "세트 완료!" 음성 안내.
- **📱 PWA (홈 화면에 추가)**: 브라우저 메뉴에서 '홈 화면에 추가' 또는 '앱 설치'를 누르면 네이티브 앱처럼 설치 및 오프라인 사용 가능.
- **📋 기록 공유**: 운동 완료 시 카카오톡/SNS 공유용 텍스트 클립보드 복사 기능.
